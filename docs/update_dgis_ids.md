# Обновление отсутствующих dgis_id

Данный инструмент позволяет заполнить отсутствующие ID из 2GIS для записей в базе данных, у которых поле `dgis_id` пустое или отсутствует.

## Использование

### Через основной скрипт:
```bash
python tools/update_missing_dgis_ids.py --db путь/к/вашей/базе.db [опции]
```

### Через упрощённый запуск:
```bash
python run_update_dgis_ids.py --db путь/к/вашей/базе.db [опции]
```

## Параметры

- `--db` - (обязательный) путь к файлу SQLite базы данных
- `--headless` - запуск браузера в фоновом режиме (без GUI)
- `--concurrency N` - количество одновременных задач (по умолчанию: 5)
- `--delay SECONDS` - задержка между запросами в секундах (по умолчанию: 0.5)
- `--limit N` - ограничение количества обрабатываемых записей (0 = все)
- `--city NAME` - название города для поиска (переопределяет город из базы)

## Примеры

Обновить все отсутствующие ID в фоновом режиме:
```bash
python tools/update_missing_dgis_ids.py --db my_database.db --headless
```

Обработать только 10 записей с задержкой 1 секунду:
```bash
python tools/update_missing_dgis_ids.py --db my_database.db --headless --limit 100 --delay 1.0
```

Обработать записи для конкретного города:
```bash
python tools/update_missing_dgis_ids.py --db my_database.db --headless --city irkutsk
```

## Алгоритм работы

1. Скрипт находит все записи в таблице `buildings`, у которых `dgis_id` IS NULL или пустой
2. Для каждой записи формируется поисковый запрос на основе улицы и адреса
3. Открывается страница поиска на 2GIS и происходит попытка найти соответствующий ID
4. Найденный ID записывается в поле `dgis_id` базы данных
5. В случае неудачи запись помечается как обработанная, чтобы избежать бесконечных попыток

## Зависимости

- playwright (установка: `pip install playwright`)
- браузер chromium (установка: `playwright install chromium`)
