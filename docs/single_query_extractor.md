# Извлечение ссылок "внутри зданий" из 2GIS

## Описание

Программа `single_query_2gis_extractor.py` позволяет выполнять одиночные поисковые запросы к 2GIS и извлекать ссылки на организации "внутри зданий".

### Функциональность

- Выполняет поисковый запрос (например, "ТЦ") в указанном городе
- Переходит на страницу результатов поиска: `https://2gis.ru/irkutsk/search/ТЦ`
- Заходит в каждое здание из результатов
- Нажимает на вкладку "в здании"
- Извлекает ID из URL после перехода во вкладку "в здании"
- Генерирует список ссылок в формате: `https://2gis.ru/irkutsk/inside/[ID]`
- Сохраняет результаты в текстовый файл

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Использование

### Базовое использование

```bash
python single_query_2gis_extractor.py --query "ТЦ" --city irkutsk
```

### Параметры командной строки

- `--query`, `-q`: Поисковый запрос (обязательный параметр)
- `--city`, `-c`: Город для поиска (по умолчанию: irkutsk)
- `--out`, `-o`: Выходной файл для сохранения ссылок (по умолчанию: 2gis_inside_links.txt)
- `--limit`, `-l`: Максимальное количество результатов для обработки (по умолчанию: 1)

### Примеры

Поиск торговых центров в Иркутске и извлечение первых 5 результатов:

```bash
python single_query_2gis_extractor.py --query "ТЦ" --city irkutsk --limit 5 --out tc_links.txt
```

Поиск ресторанов в Москве:

```bash
python single_query_2gis_extractor.py --query "ресторан" --city moscow --limit 3
```

## Важные замечания

- Программа использует браузер Chrome в фоновом режиме для имитации действий пользователя
- Может потребоваться установить Chrome, если он еще не установлен
- Работа с 2GIS может быть ограничена антибот-защитой, поэтому рекомендуется не делать слишком частые запросы
- Программа сохраняет только уникальные ID зданий
